# Stitch 重设计 · 设计意图清单

> 来源：Stitch 项目 `ZSXQ Exporter Reading App`（projectId `6747984405208617254`，DESKTOP）
> 本文档仅记录设计意图，供后续前端落地参考，不涉及任何代码改动。

## 全局设计系统（Design System）

整套设计取名 **"Calm Editorial"（沉静编辑式）**，理念是把"原始数据导出"做成一种**有档案质感的阅读体验**，靠近"慢网/纸质书房"的气质：克制、可靠、耐看，降低认知负担。风格是 **现代极简 + 轻度拟物/纸感** 的混合。

### 配色

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 surface/background | `#FAF9F6` | 暖白纸面，全站底色（非纯白，减少眼疲劳） |
| 卡片 surface-container-lowest | `#FFFFFF` | 纯白卡片，像"摊在桌面上的纸" |
| 卡片分层 container-low/high | `#F4F3F1` / `#E9E8E5` | hover 与层级区分 |
| 主色 primary | `#16452F`（深森林绿） | 主按钮、品牌强调、链接 hover |
| 主色容器 primary-container | `#2F5D45` | 按钮 hover 态、品牌色 |
| 强调色 secondary | `#8A501B` / 暖赭 `#B8763E` | 高亮、标签、分类点缀 |
| 正文 on-surface | `#1A1C1A` | 主文字（近黑墨色） |
| 次要文字 on-surface-variant | `#414943` | 辅助说明、metadata |
| 边框 outline-variant / 自定义 | `#C0C9C1` / 发丝线 `#ECE8E1` | 卡片 1px 描边 |
| 错误 error | `#BA1A1A` | 错误态 |

颜色模式为 **LIGHT**（不默认暗色，HTML 仍带 `dark:` 类做了暗色映射但主用浅色）。

### 字体

双字体策略，明确区分"内容"与"界面"：

- **标题 / 长文阅读：Source Serif 4（衬线）** — 文学、权威的调性。
  - `headline-xl` 48px / 700 / line-height 1.1 / letter-spacing -0.02em
  - `headline-lg` 32px / 600 / 1.2 / -0.01em（移动端 28px）
  - `headline-md` 24px / 600 / 1.3
- **界面 / 导航 / 标签 / 元信息：Inter（无衬线）** — 中性，平衡衬线的个性。
  - `body-lg` 18px / 400 / line-height **1.6**（长文阅读用，呼吸感强）
  - `body-md` 16px / 400 / 1.5
  - `label-md` 14px / 500 / 0.02em；`label-sm` 12px / 600

### 间距节奏

- 采用 **"reading-optimal" 居中容器**：主内容最大宽度 **800px**（`container-max`），保证每行 70–80 字符的舒适阅读宽度。
- 垂直节奏以 **1.5rem（24px，`space-md`）** 为基准增量；大区块之间用 **4rem（64px，`space-xl`）** 拉开。
- 页边距 `margin-page` 2rem（移动端收到 1rem），栅格间隙 `gutter` 1.5rem。
- "generous-first"（先给足留白）原则。

### 形状与圆角

- 招牌圆角 **14px（`card-radius` / rounded-lg）**，用于所有主卡片和容器。
- 按钮/标签可用 8px 或沿用 14px 做胶囊感。
- 圆角设定 `ROUND_EIGHT`，图标用 1.5pt 线性描边、圆头端点。

### 高度与深度

不用传统投影，靠 **色调分层 + 低对比描边** 表达深度：

- 背景 `#FAF9F6` 是"桌面"，白卡 `#FFFFFF` 是"纸"。
- 分隔靠 **1px 发丝线 `#ECE8E1`（`.card-border`）**，不靠阴影。
- 仅模态等高聚焦场景才用极柔和的环境投影（8% 不透明、20px 模糊，带主色暖调）。
- **hover 不做 Z 轴抬升**，而是用背景色微移 / 边框加深来提示可交互。

### 关键组件约定

- **顶栏 TopNavBar**：固定吸顶，高 64px（h-16），`bg-surface/80 + backdrop-blur-md` 半透明毛玻璃，底部 1px 描边；左侧衬线品牌名 `ZSXQ Exporter`，中间 Inter 导航（导出/分析/生成，当前页用 2px 下划线 + 主绿），右侧设置齿轮图标。
- **主按钮**：森林绿底 `#16452F` + 白字，14px 圆角，hover 转 `primary-container`。
- **次按钮（Ghost）**：透明底 + 暖灰描边。
- **卡片**：白底、14px 圆角、1px 发丝线、内边距 ≥24px（p-6），hover 切到 `container-low`。
- **输入框**：1px 描边，聚焦时主绿描边 + 2px 主色 10% 外发光（`.focus-glow`）。
- **标签/Chip**：赭色 10% 底 + 赭色字，用于分类（如导出格式）。
- **列表**：无边框条目，条目间 1px `#ECE8E1` 分隔线；标题用 Source Serif、标签用 Inter。
- **进度条**：森林绿填充 + 暖灰轨道。
- **页脚**：居中，衬线品牌名 + `© 2024 ZSXQ Exporter — Digital Mindfulness for Knowledge Archiving` + Privacy/Terms/Guide 链接。

## 逐页清单

### 1. 首页 / 连接 · Home

- **screenId**：`b429bb74c6de433ea996b29c1a0eb130`
- **标题**：`Home - ZSXQ Exporter`
- **整体布局**：单列居中，容器 **800px**。固定顶栏 → 主区分三段：①连接卡 ②三栏功能入口 ③"我的星球"骨架占位 → 页脚。
- **主色 / 强调色**：暖白底；连接卡为白底发丝线卡；主绿"连接"按钮；功能图标用主绿。
- **标题 / 正文字体**：主标题「连接知识星球」用 Source Serif（headline-lg/xl 级，深墨色）；说明文与输入提示用 Inter `body-md`，次要灰 `on-surface-variant`。
- **间距节奏**：区块间 `space-xl`(64px)；卡内 p-6；连接按钮 `mt-4 py-3 px-6`。
- **关键组件**：
  - 连接卡：标题 + 一段说明 + Token 输入框（带前缀图标 + "如何获取 Token?"下划线链接）+ 主绿"连接"按钮。
  - 三栏功能入口卡（导出内容 / 内容分析 / 智能生成）：每张 = 圆形浅底图标（hover 放大 1.1）+ 衬线小标题 + Inter 描述，整卡可点击、hover 变色。
  - "我的星球"区：衬线小节标题 + 两张灰色骨架占位卡（加载态），底部提示"连接 Token 后将自动显示你的星球"。

### 2. 导出 · Export

- **screenId**：`cc0bb229d9a14ba29fbe3d456dc50206`
- **标题**：`Export - ZSXQ Exporter`
- **整体布局**：单列居中，容器 **800px**（`max-w-container-max`）；`flex flex-col gap-space-xl`。页头标题区 → 导出设置卡 → 进度条 → 导出结果卡 → 页脚。
- **主色 / 强调色**：暖白底 + 白色设置卡；主绿"开始导出"长按钮（满宽）；进度条主绿填充。
- **标题 / 正文字体**：大标题「数据归档」Source Serif；副标题与表单标签 Inter；表单 label 用 `label-md`。
- **间距节奏**：页头 `mb-space-md`；主区块 `gap-space-xl`；进度区与结果区按 64px 节奏分隔。
- **关键组件**：
  - 导出设置卡：选择星球下拉、开始/结束日期（`mm/dd/yyyy` 带日历图标）、导出内容下拉（全部内容[主题、评论、附件]）、满宽主绿"开始导出"按钮（带下载图标）。
  - 进度条：标签"正在下载图片 32/180" + 右侧百分比"18%"，森林绿填充 + 暖灰轨道。
  - 导出结果卡：节标题「导出结果」+ 文件条目（文件名 `我的知识星球_2024.zip`、大小/时间元信息、右侧"下载"链接），条目用文档图标。

### 3. 分析 · Analyze

- **screenId**：`a3809e9b2e7b477b9ab58c0ed4c00b4b`
- **标题**：`Analyze - ZSXQ Exporter`
- **整体布局**：居中，**标题区与功能卡区放宽到 `max-w-5xl`**，文章卡回到窄阅读宽度。结构：居中大标题 → 三栏分析能力卡（grid-cols-3）→ 居中长文复盘卡 → 页脚。比首页/导出更"杂志感"。
- **主色 / 强调色**：暖白底；分析卡白底；引用块用 **主绿左边线**（`border-l-4 border-primary`）。
- **标题 / 正文字体**：居中主标题「内容分析」Source Serif headline；文章卡内 `.prose` 排版，h2「本周星球动态复盘」用 `headline-lg`，正文 Inter，行高宽松；引用块斜体 + 次要灰。
- **间距节奏**：功能卡区 `mb-space-xl`、`gap-6`；文章卡内小节标题间距 `mb-4 / my-6`。
- **关键组件**：
  - 三栏能力卡（复盘报告 / 关键词提取 / 趋势分析）：居中图标 + 衬线标题 + 描述，风格同首页功能卡。
  - 长文复盘卡（`<article class="prose">`）：日期副标题（2024年x月 第x期）、多个小节（核心议题概览 / 活跃度洞察 / 优质内容摘录）、引用块（左主绿竖线 + 斜体 + 署名"—— 用户 @Thinker"）、右下角"由 Claude 生成"标记。

### 4. 智能生成（双栏布局）· Generate

## 落地提示（备忘）

- 两个"智能生成"页是**同一功能的两种布局方案**：第 4 页桌面双栏工作台、第 5 页单列堆叠（更适合窄屏 / 移动）。落地时需决定主用哪一种，或按断点切换（≥md 双栏、<md 单列）。
- 容器宽度并非全站统一 800px：阅读/表单类页用 800px；分析页功能卡区放宽到 5xl；生成双栏页用 1200px。需要在落地时把这套"按页面类型选容器宽度"的规则固化。
- 所有页面共享同一套顶栏 / 页脚 / 卡片 / 按钮规范，建议先抽出设计令牌（颜色、字体、间距、圆角、发丝线）和基础组件，再逐页拼装。
